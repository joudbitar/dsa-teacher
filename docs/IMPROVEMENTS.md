# DSA Lab Improvements & Ideas

This document tracks improvements, enhancements, and ideas for the DSA Lab platform.

## Stack Java - Create Class Challenge

### Issues & Improvements

1. **Initial Capacity Not Specified**
   - **Problem**: Users have to figure out the initial capacity for the array-based Stack implementation themselves
   - **Impact**: Creates unnecessary confusion and trial-and-error
   - **Proposed Solution**: 
     - Add the initial capacity requirement to the challenge instructions
     - Specify in hints or requirements: "Use an initial capacity of 10 for the array"
     - Or provide it as a constant in starter code comments
